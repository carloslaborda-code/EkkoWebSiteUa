# EkkoWebSiteUa
Pagina web para la asignatura de Usabilidad y Accesibilidad de la Universidad de Alicante, en la que desarrollaremos una web con la pila MEAN centrandonos en el front-end. La web trata de un sistema de busqueda de contenido de peliculas y sonidos multimedia donde buscaremos por un fragmento o frase un trozo especifico de un autor, actor, sonido.
